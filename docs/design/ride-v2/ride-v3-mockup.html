Ride screen v3: the row grid

Built on docs/design/PRINCIPLES.md: one 64 px unit (a 44 px button plus 10 px padding on each side), 8 px gaps, every tile n × 72 − 8 px high. Components come in steps (S, M, L, XL) instead of scaling. The layout counts how many rows fit and gives the spare rows to the pacing box first.

The faint blue bands are the rows. Turn them off to judge the look.
